# 源音效管理工具 0.12.0 · Mac 修复版试用

适用 macOS 27 或更新版本、Apple M 系列芯片。

1. 退出正在运行的旧版源音效管理工具。
2. 打开 `源音效管理工具-macOS27-Apple芯片-0.12.0-Mac修复复测.dmg`。
3. 将“源音效管理工具.app”拖到“应用程序”；已有旧版时替换应用。
4. 从“应用程序”打开软件。先使用测试音乐目录试用，再连接公司音乐库。通过 Finder 挂载服务器后，在软件中选择 Mac 上的共享目录；Windows 的 `Z:\` 路径不能直接使用。

本次修复了上一轮已复现的 Qt 原生无障碍闪退路径。Mac 回传自动测试 27/27、最终插件原生测试 12/12、针对性重复测试 30 次通过；本机已核验镜像内容、哈希和修复插件身份。

本包尚未完成 Apple Developer ID 签名与公证，macOS 可能阻止首次打开。如果确认包来自这次交付，可在系统“隐私与安全性”中查看该应用的打开提示；不要关闭全局安全保护。受公司设备管理限制时请按公司的安装规则处理。

仍需在实际使用环境确认：公司 NAS 共享缓存、波形/名称拖入达芬奇后引用原文件，以及单曲/文件夹“仅从列表移除”与恢复的界面流程。本版是内部试用包，不将这些项目标为已通过。

安装镜像 SHA-256：

```text
cb90ec376f374cef8d2ee9277b042604ff2e2d940c68aa9c75ae30171fd80be5
```

Mac 可在终端输入 `shasum -a 256 `（末尾保留空格），将 DMG 拖入终端后回车；结果应与上面的值一致。
