# 0.11.1 完善范围

本轮优先处理已能从代码和测试中确认的问题。继续使用现有深浅主题、行内波形和服务器原文件工作流。

1. 保存收藏、标签时使用后台任务；失败不显示已保存状态，快速切换音乐不会把标记写到另一首。保存后重新核对当前收藏/标签搜索的成员。
2. 左侧查找文件夹在取消中文输入法拼写后，继续搜索已经输入的文字。
3. 仅从列表排除文件夹或音乐时保留本机收藏、标签及有效时长，恢复收录后带回。原文件变化时旧时长失效。
4. Windows 安装和卸载开始前检查程序文件是否正在使用。旧版仍运行时提前停止，保留原安装；对隔离安装目录验证升级与卸载。
5. 旧波形异常记录按当前音乐库筛选。已移除或排除的音乐不参与计数和重试，分页前就排除这些记录，避免空页挡住后面的有效记录。

验证先记录原问题，再执行针对性回归、完整测试、打包后的运行检查。所有文件操作测试使用专门创建的临时目录，不删除或移动正式音乐。

暂留后续：磁盘波形缓存容量管理、NAS 离线状态与重连提示、外部重命名后的安全索引核对。这些需要独立设计，避免误清理原音乐或把临时断网误判为文件删除。NAS 原文件回收站操作目前在线程中执行，极端断网时仍可能长时间等待并阻止正常关窗；后续应使用能核对操作结果的独立进程，不能直接杀掉任务后假定删除失败。情绪识别与 Mac 实机验收继续保留原有边界。
