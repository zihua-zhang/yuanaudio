# 0.8.0 共享波形、后台让路与个人选曲工作区

日期：2026-09-25。Windows 预览版。按确认的第 1、3、4、5 项实施，不加入近期试听音频文件缓存。

## 实现与约束

- 现有库可接入共享缓存，本机库身份保持，共享身份单独保存。升级当前 0.7 使用的版本 3 索引前，保存并校验 `library.pre-0.8.sqlite`；不覆盖已有有效备份。原文件、收藏和标签不迁移到共享盘。
- 专用缓存可以位于音乐根目录内。验证真实目录身份，拒绝音乐根目录/上级目录作为缓存，扫描在进入缓存子目录前排除。已有有效共享配置可复用；不接管非空无配置文件夹。
- 完整本机波形可发布到独立的共享显示缓存，不读取音乐内容；以共享库身份、相对路径、大小和修改时间匹配，并校验缓存内容。该层不冒充源文件指纹缓存。参考波形不作为完整数据上传。
- 普通共享生成通过所有者标识与单调观察进度协调。正常请求可等待并复用其他客户端的结果；等待有期限，异常恢复允许本机继续，故不能承诺所有情况下绝不重复解码。不会用本机进程号或跨主机时间判断另一个客户端死亡。
- 默认剪辑优先，后台读取 1 MiB/s。试听、目录扫描和持续系统 CPU 高负载时让路；手动暂停与自动让路分开。负载检测仅有后台工作时运行；播放暂停时停止周期位置上报。CPU 高负载连续两次采样进入让路，低负载连续三次恢复，避免频繁开关。
- 失败记录独立本机持久化，支持原因筛选、分页、仅重试已记录失败、参考条目抽查。数据库写入失败时保留待写记录，不推进持久续跑游标；共享发布必须有成功完成回执，本机已有图不代表共享成功。
- 全库核对每批最多处理 50 条已缓存记录，同一时间只有一个记录写入任务；写完再继续，多次进度请求合并。前台波形显示不等待后台写入，避免慢盘时任务无限积压。
- 个人工作区含多份候选清单、最近 100 首真实试听、常用目录。以素材库及相对路径保存引用；播放时查询当前索引版本，较新的列表点击会取消过期工作区请求。名称/目录匹配高亮，悬停波形显示时间，原文件拖放契约保持。

## 验证记录

开发中的针对性检查已覆盖共享身份保留、升级备份、嵌套目录排除、六客户端生成与中断恢复、播放暂停无周期回调、后台让路、仅失败重试、持久游标恢复、分类分页过期响应隔离、工作区持久化和原文件 URL。

本机独立演示资料的原生界面检查涵盖 1320 宽窗口及 980×640 最小客户区、工作区展开、缓存面板展开和共享设置。发现工作区高度挤占目录树，已减小列表最小高度并将普通提示压成单行，保留完整悬浮说明。

共享生成额外重复 20 轮，每轮 6 个客户端：120 个请求中每轮只解码一次。六客户端在生成者中断后也能恢复，本机测试耗时 10.172 秒；前台等待超时后的回退仍可能重复工作。

阻塞数据库写入的测试使用 1,000 份本机波形（含 250 份参考波形），确认待处理记录、游标推进及写入任务数量受限，已缓存波形仍可显示。释放阻塞后完成核对，本机隔离资料耗时约 502 ms；该数字不代表 NAS 吞吐。

最终 Release 构建完成，CTest **20/20 组全部通过，总耗时 119.93 秒**。涵盖索引、共享协议、六客户端生成与中断恢复、工作区、界面恢复、异常恢复、后台策略、扫描让路、真实播放定位、限速、解码、缓存并发及大元数据进度。

对打包目录内的程序另行运行真实播放器定位和工作进程集成检查，均通过。包内程序与构建程序 SHA-256 一致：`76dc412dca645f9bdb82c9d609d9863f39a62205ca791b1f1ff84d852845ce02`。

从 Windows 文件资源管理器打开正式新版，使用用户实际资料目录：59,443 首索引保留；上次准备显示 59,429 份缓存（其中参考波形 7,072 份）、14 条失败。正式界面成功接入 `Z:\剪辑音乐\音频缓存`，列表原有波形仍可显示。异常窗口列出 14 条旧失败，并说明历史参考波形明细尚未全部收录，需重新核对缓存。

正式包在 980×640 最小客户区检查了工作区、波形列表、共享设置及异常详情。缓存和工作区均可收起，恢复目录树与列表空间。全库共享补齐为独立后台工作，本轮功能回归通过不代表 1 TB 素材全部准确分析或共享同步完成。

正式库、980×640 窗口、异常详情打开、未试听和未启动全库准备时，对主界面进程做了一次 20.03 秒短时采样：累计 CPU 0.4531 秒，约单核 2.262%；结束时工作集 97.93 MiB、私有内存 70.62 MiB。未合计子进程，不与旧版不同场景横向对比，也不代表持续浏览或批量准备的资源上限。

接入后已启动全库核对及共享补齐，现场观察进度由 63 推进到 432 / 59,443，包含 136 份参考波形、1 次本轮失败；已有完整波形参与共享，缺失和失败项另行尝试生成。这是运行中的阶段记录，不是全库完成结果。桌面原有唯一“音频素材库（波形缓存版）”快捷方式已更新至 0.8.0。

交付便携 ZIP 逐文件校验 SHA-256 并检查 CRC；包内不含个人索引、候选记录或音频。校验清单位于 dist 中同名 `-manifest.json`。Windows 程序未做发行签名。

## 边界

本机模拟多进程不等于公司 NAS 上六至十人验收。首次无缓存仍需读音乐并解码；共享显示缓存不能保证发现保留大小和修改时间的人工替换。背景限速不覆盖试听、指纹和缓存读写，也不是全公司总带宽限制。CPU 让路不检测达芬奇 GPU 渲染。

Mac M4 Pro/macOS 27、达芬奇 20/21 工程内真实拖放、1 TB 全库吞吐及长期公司多人负载尚未验收。没有依据声称全面超过出片。历史参考计数不是精确分析通过数量，旧版未保存的明细不能凭总数恢复。
