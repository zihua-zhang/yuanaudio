# 0.9.2 参考波形显示与时长

日期：2026-09-25。Windows 预览版。

## 用户可见的变化

- 参考音频的波形使用中性色；波形起点保留一个小标志，悬停提示其位置仅供参考。不再用整段黄色和末尾文字遮住波形。
- 列表“时长”使用已有参考波形给出带“约”的估算值；试听时若播放器从原音乐取得时长，更新成普通时长。估算不写入准确时长字段。
- 波形仍可点击定位试听、拖动整首服务器原文件到达芬奇。参考状态的含义不变，已有后台复核及共享缓存继续运行。
