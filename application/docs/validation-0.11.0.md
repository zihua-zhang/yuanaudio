# 源音效管理工具 0.11.0 验证记录

## 本轮实现

- “设置 → 素材库”逐项列出已连接的音乐目录，允许继续添加多个库，并对选中库刷新或移除。目录树中的库根、下级文件夹和音乐行均有明确的移除入口。
- “仅从列表排除”只修改本机 SQLite 索引。单曲和文件夹的排除记录持久保存，重新扫描不会收回；设置页可撤销排除并重新收录。整库移除后可重新添加。其他音乐库、原音频与共享波形缓存不参与这些数据库事务。
- 另设“移入系统回收站并从列表移除”。对整个库需输入库名确认；原件路径必须经过库根、链接与其他活跃库/共享缓存重叠检查。系统回收站不可用或移动失败时不进行索引移除，也不回退为永久删除。大目录移动在后台执行，窗口会提示等待。
- 移除时停止正在运行的扫描；旧扫描批次与旧目录查询不能重新带回被排除的项目。被移除曲目的试听选择和可见波形任务随目录变更更新。
- 吸收 0.10.0 Mac 实机构建返回的头文件路径、打包依赖与平台测试修正；为 Mac 共享缓存初始化增加无覆盖硬链接后备方案。该后备方案在公司 SMB 上仍需实机复测。

## Windows 自动验证

使用 Qt 6.9.3、MinGW 13.1、CMake Release 构建。最终完整 CTest **27/27 通过**（140.88 秒）；源文件路径保护、库/目录模型删除、持久排除与恢复、多库隔离、扫描进程、界面操作均有独立验证。本轮首次全套执行时，`scan_policy` 测试的 Python SQLite 连接在 Windows 清理临时目录前没有关闭，导致文件占用；修正测试资源清理后，受影响的三项测试及最终完整套件均通过。完整结果见 `test-output/ctest-0.11.0-final.log`。

已生成 Windows 安装版和免安装版，并从打包暂存目录以精简系统环境启动正式程序执行独立的 `worker register` 冒烟检查，进程正常退出并返回 `registered`。桌面上的安装包及 Mac 同事构建包与 `dist` 源文件逐项比对 SHA-256 一致；旧版桌面文件已移入 `dist/archive/desktop-0.10.0` 保存。

本轮测试用临时文件验证原件保持不变与路径拒绝逻辑；**没有对公司 NAS 执行任何文件删除或回收站移动**。系统回收站对特定 SMB 共享的支持，仍需在专门创建的测试目录内实测。
