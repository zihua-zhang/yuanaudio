# 0.9 完整列表与二级设置

用户确认方向：取消音乐列表“加载更多”，一次展示当前范围全部曲目；缓存与低频配置放进二级菜单；文件夹缩进紧凑。延续浅色、克制、接近系统工具的风格，主任务是短剧选曲与原文件拖入达芬奇。

## 视觉与结构

- 纸白 #ffffff 用于列表与设置内容；雾灰 #f5f5f7 用于窗口；侧栏 #eef0f3；正文 #1d1d1f；次级文字 #6e6e73；交互蓝 #007aff。
- 系统字体：Windows Segoe UI / Microsoft YaHei UI，Mac PingFang SC；正文 13 px，分组标题 15 px，页面标题 22 px。正文左对齐，数值与控件在右侧对齐。
- 主窗口：顶部名称、搜索、目录操作、设置；中部紧凑目录树和连续波形列表；底部紧凑播放器。缓存只保留状态栏轻提示，点击进入设置，不占一整排列表高度。
- 设置窗口：左侧六项导航，右侧可滚动内容，底部关闭。播放与浏览、波形缓存、性能、显示、素材库、快捷键。设置立即应用；关闭不暂停准备、不打断试听。所有选项连接真实行为，不提供空开关。

## 性能约束

从本机索引后台取得完整轻量曲目信息，保留筛选、排序及一致性快照；取消旧查询并丢弃过期结果。只绘制可见行，波形缓存继续有界。素材 ID 直接定位行，消除播放与波形更新时反复遍历全部结果。查询失败保留旧结果和试听。全量文字占用需以 6 万与 10 万条实际基准记录，不宣称与 50 条相同。
