# 源音效管理工具 0.11.1 验证记录

日期：2026-10-02。

## 本轮改善

- 收藏、标签保存移到后台，写入成功后才更新已保存状态。失败保留原状态并允许重试，快速切换音乐不会串写；正在返回的旧搜索结果也不能覆盖刚保存的标记。收藏或标签搜索会同步更新成员，保持试听。
- 取消中文输入法组词后，文件夹搜索继续查询已经输入的内容。
- 单曲或文件夹仅从列表排除时，在同一个数据库事务内保存收藏、标签和时长；恢复收录后带回。文件大小或修改时间变化时不恢复旧时长。记录 ID 被其他歌曲占用时不会覆盖其他歌曲。
- 已移除或排除的音乐从波形异常的有效计数、分页和重试范围中排除，避免旧记录再次触发服务器读取。历史记录保留，恢复素材后仍可用；索引读取错误会明确报错，不会改用旧路径继续分析。
- Windows 安装、升级和卸载开始前检查被占用的程序文件、插件和目录链接。旧版运行中升级会在调用旧卸载程序前停止；检查失败保留原安装文件。文件删除失败时保留快捷方式和安装记录。

## 验证结果

- 修改前的完整基线：27/27 通过。针对新发现的问题补充了能复现旧行为的失败用例，再完成修复。
- 最终 Windows Release 构建成功；完整 CTest **27/27 通过，139.15 秒**。日志：`test-output/build-and-tests-0.11.1.log`。其中核心测试覆盖元数据恢复及事务回滚，界面测试覆盖异步保存、搜索结果竞争和输入法取消，异常页测试覆盖前 100 条已排除而后续仍有有效记录的情况。
- 安装器 **9/9 检查通过**。使用独立目录和占位程序实际执行安装、升级、卸载，验证运行中程序、被占用 DLL、嵌套目录链接、系统目录拒绝及无关文件保留。测试版本不写入真实快捷方式或注册表。日志：`test-output/installer-safety-0.11.1.log`。
- 从当前正式索引创建只读快照，对副本执行升级。**59,482 首音乐、2 个音乐库**的原有表内容逐行摘要一致，目录与排除规则保持，SQLite 完整性检查通过。该真实副本没有收藏或标签；非空个人标记的恢复由专门构造的回归用例验证。结果：`test-output/upgrade-0.11.1/library.verification.json`。
- 在该副本上测量 26 种查询、520 次样本：含数据库连接开销的中位数 1.57 ms、95% 分位 4.43 ms、最大 41.19 ms。这个工具查询的是首批结果，**不是完整列表就绪时间、网络速度或与其他软件的比较**。
- 浅色、深色模式在 Windows 原生窗口中完成切换与持久化检查，中文字体和布局截图已查看。原生界面检查 3/3 通过（含初始化和清理）；结果：`test-output/native-ui-tests-0.11.1.txt`，截图位于 `test-output/native-ui-0.11.1/`。
- 打包后的正式程序在只保留软件目录和 Windows 系统目录的运行环境中，通过注册、扫描、断线保留索引、立体声解码、本机/共享波形复用、损坏缓存恢复和播放控制检查，测试原音频内容保持。日志：`test-output/packaged-workers-0.11.1.log`。

## 使用与剩余边界

本版会将本机索引升级到结构版本 6。原音乐及共享波形不需要重新生成。新增的个人标记保留只对本版之后的单曲/文件夹排除生效；旧版已经丢失的标记无法凭空恢复。整个音乐库移除后重新添加仍按新接入处理。

Mac 源码同步至 0.11.1，仍需在 Mac 上构建并验收；Windows 测试不能代替 macOS、达芬奇直拖、1 TB 全库及 6–10 人真实并发验证。NAS 原文件回收站操作未对正式音乐执行。极端断网时此操作仍可能长时间等待并阻止正常关窗，后续应改为可核对结果的独立任务。安装器暂未提供磁盘写满、突然断电后的完整自动回滚，也未做发行签名。

后续优先方向：NAS 离线与重连提示、磁盘缓存容量查看和安全清理、外部移动或重命名后的索引核对。见 `docs/improvement-plan-0.11.1.md`。
