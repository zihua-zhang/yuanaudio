# 源音效管理工具 0.12.0 验证记录

日期：2026-10-02。

## 本轮界面

依据用户选定的第一轮「清透浅色 / 石墨深色」制作同一套布局。采用平整工作区、统一线条图标、名称与路径双层列表、浅缩进目录和全宽紧凑播放条。设置入口保留在顶栏；缓存管理仍在二级设置中。

新增底部试听进度条，点击或拖动松手后定位当前音乐。音频行的点选试听、波形和名称整首拖出、参考波形小标记及原文件引用保持。主题切换只刷新外观，不重新搜索或启动解码。

## 兼容与边界

本版继续使用索引结构版本 6；原文件、索引和共享波形无需重建。图标缓存限额 2 MiB，波形按现有缓存限额和可见行策略绘制；没有新增全库常驻控件、持续装饰动画或实时模糊。

Windows 测试不能代替 macOS 27 上的原生构建、达芬奇接收原文件、真实公司 NAS 并发验收。Mac 同步提供 0.12.0 同事构建包，尚不是已经实测的新 DMG。安装包仍未做发行签名。此前的数据管理与安装回滚边界继续见 `validation-0.11.1.md`。
