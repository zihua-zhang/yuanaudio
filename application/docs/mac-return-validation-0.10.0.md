## 回传的 Mac 实机结果

回传报告标明测试设备为 Apple M4 Pro、macOS 27.0（26A428）。构建日志记录 CTest **25/25 通过**，`codesign --verify --deep --strict` 通过，`hdiutil verify` 显示镜像校验有效。报告记录应用已安装至 `/Applications` 并启动；独立 SMB 测试音乐目录的搜索、行内波形、试听，以及已有 `library.json` 的共享缓存读取与复用正常。这些是回传文件中的实机观察，无法在 Windows 上重复执行。

达芬奇 Resolve Studio 20.3.2 能直接从同一 NAS 路径导入测试 MP3，媒体池记录服务器原路径。**从本软件拖进达芬奇媒体池或时间线的实际拖放未完成**；自动测试中的拖拽 MIME 不能替代这项验收。

## 发布与使用限制

- 该 DMG 仅有 ad hoc 签名，回传的 `spctl --assess` 为 `rejected`；尚无 Developer ID 签名和公证，不应视为已完成正式多人分发。
