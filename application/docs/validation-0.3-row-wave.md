# 列表波形版 0.3 验证记录

2026-09-20，Windows 11；Qt 6.9.3、FFmpeg 7.1.1、MinGW 13.1。

## 交付范围

保留原 0.2，另外提供“列表波形版 0.3”。独立源码工作目录 `audio-library-waveforms`，独立便携程序目录和桌面快捷方式。两个版本有意共用本机索引、收藏、标签与磁盘波形缓存，数据库结构未变。程序数据不是两个隔离的副本。

每行音乐名称后显示整首波形；点击相对位置，先定位再播放。暂停状态点击也会播放，不受“选中后试听”开关限制。点击另一行可直接换曲定位。音乐名称仍输出整首原文件 URL 供外部拖入，波形手势不会误触文件拖出。底部大波形和行内播放位置同步。

## 性能与一致性实现

- 自绘列表单元格，不为每条结果创建播放器或完整波形控件。
- 160 ms 滚动防抖，只排入当前可见行；每次最多一个波形工作进程，选中歌曲优先。取消后等旧进程退出才启动下一项，忽略过期输出。
- 完成的内存波形约保留 128 首，保护可见和选中条目，避免反复解码。磁盘缓存沿用 0.2 格式。
- 未命中缓存的后台解码源读取按每窗口 1 MiB/s 控制，初始余量 256 KiB；重新定位读取的字节也计入。点击该曲会撤销限速任务并按前台优先级重新请求。从前台任务切到已有缓存歌曲时，会取消旧前台任务，防止其变成无约束后台读取。
- 指纹读取、缓存读写和试听不在该解码预算内，因此此预算不是严格的 NAS 全部流量上限。每任务 120 秒超时；很大或网络很慢的音乐仍可能需要点击重试。
- 显式刷新素材库后清空内存波形，重新进入文件版本、头尾指纹及磁盘缓存校验路径。相同大小、相同修改时间但内容被替换的测试文件也会更新波形。指纹不是整文件哈希；原件修改后应主动刷新。
- 播放进程保存最新定位请求，等媒体时长和可定位状态就绪后才设置位置并播放；过期歌曲命令无效，准备中暂停可以取消自动开始。

## 自动测试

七组 CTest 全部通过，最后一次完整源码测试约 16.8 秒。

| 检查 | 验证内容 |
|---|---|
| core_contracts | 原有八项索引、中文搜索、缓存、原文件拖放数据契约 |
| window_recovery | 八项真实窗口/子进程测试：可见行与隐藏行隔离、点击六成和四分之一位置、暂停后点击、前后台任务切换、同大小同时间文件替换后刷新、离线恢复、快速切歌及搜索 |
| worker_integration | 原有注册、收录、离线保留、缓存、播放/暂停/跳转、旧命令隔离、封面 MP3 |
| waveform_cue | 首次播放状态已处于点击位置、载入中最新点击优先、旧代际点击无效、准备中暂停 |
| background_read_budget | 3 MB 合成 WAV 冷读取受预算约束，前台和缓存命中不受该延迟，生成波形字节相同 |
| decoder_regression | 封面、非静音峰值、中文路径、损坏尾部、截断音频、伪文件与原件不变 |
| cache_concurrency | 原有十个模拟客户端的共享缓存和初始化竞争验证 |

另完成 300 次连续切歌与旧命令隔离压力测试，最终歌曲正常推进，播放进程正常退出（约 11.8 秒）。

九种编码检查通过：WAV PCM24、MP3、FLAC、M4A、OGG、AIFF、AAC、Opus、WMA。

最终便携包另在不加入开发 SDK 路径的环境中通过点击定位与后台预算检查。3 MB 合成 WAV 的后台测试用时 2.906 秒，前台 0.047 秒，本机缓存 0.031 秒；这是本机合成素材验证，不是 NAS 吞吐成绩。打包 EXE 与测试通过的构建产物 SHA-256 一致。

新增用例曾在缺少功能的实现上失败：原播放器点击六成仍从约 0.1 秒开始；原界面没有行内波形；后台无读取预算时约 0.047 秒就读完测试文件；切到缓存歌曲时旧前台任务仍完成。对应实现修改后全部通过。测试主要使用临时本机音频，不向 NAS 写入测试文件。

独立代码复查指出并修复后台带宽缺失、内存缓存刷新不重新验证源文件，以及切到已缓存歌曲后旧任务继续全速读取的问题；最终复查无新增实质性问题。

## 实际窗口

便携程序在当前 Windows 工作站打开，直接显示原有 59,443 首索引，未重新扫描整库。可见的多首真实音乐后显示不同波形；点击一首 2:20 音乐约六成的位置，实际界面显示从 1:24 开始，行内与底部游标同步。测试时试听音量设为零。程序读取音乐原件，缓存和时长写入本机数据目录。

## 验收边界

这次交付 Windows 预览版。没有 Apple Silicon Mac 实机，未生成或验证 Mac 安装包；Resolve 当前停在 Studio 激活页，未在工程内完成外拖验收。公司的真实 6–10 人并发、整个 1 TB 库的冷缓存生成与总吞吐未实测。十个本机模拟客户端通过不能替代这些验收，也不能保证首次未缓存波形立即出现。

无新增情绪识别、自动扫描、缓存清理、共享标签或片段导出功能。此版专注行内波形试听及其后台读取控制。
