# 开发预览 0.1 验证记录

日期：2026-09-20。环境：本机 Windows 11 / AMD Ryzen 5 9600X / 约 32 GB 内存；Qt 6.8.3、MinGW 13.1，Release 构建。

## 已执行

1. Qt 核心行为测试：8 项，全部通过。包括中文单字/两字/目录组合、关闭重开离线查询、重扫保留收藏标签、字面目录范围与分页、逐声道反相峰值/有界内存/校验、缓存重复发布/版本变化、原件拖放 URL、Unicode 路径/索引版本变化、阻止错误覆盖音乐根目录。部分测试同时验证多种相关行为。
2. 后台进程集成测试：真实创建音频、实际启动交付程序的子进程；库身份复用、扫描、目录不可达时保留旧索引、立体声解码、本机与另一客户端缓存复用、损坏重建、音频原件字节不变、播放/暂停/定位/切曲与丢弃过期指令均通过。
3. 对便携包运行额外格式检查：24-bit WAV、MP3 VBR、FLAC、AAC/M4A、Vorbis/OGG、AIFF 的合成样本均生成完整波形。不是覆盖全部编码参数的格式认证。
4. Windows 真实桌面检查：添加独立测试目录（4 首合成音）、显示目录树、组合查询“伤感 雨夜”得到 1 条、显示 24 秒立体声波形、播放进度前进、暂停、点击波形定位到约 6 秒、无标签时收藏保存成功。
5. 更新包桌面复查：重开保留收藏，波形命中本机缓存；主动结束本软件的测试播放子进程后，主窗口仍响应，点击播放成功重启子进程，进度再次前进。
6. 独立代码审查发现并修复 4 项问题：库根目录静默覆盖、并发注册任务所有权、部分波形时间比例、树选择与查询范围不一致。复查确认四项修复，没有新增阻断本机预览的问题。

CTest 包含核心测试与后台集成测试两组，最后一次打包前两组全部通过；测试音频均由工具合成，没有改写公司的音乐。

## 性能基线

对本机 SQLite 中 **100,000 条合成元数据**执行 160 次查询（8 种查询循环，包含匹配 10,000 / 100,000 条的常见词与空结果）；首屏最多 50 行。

| 指标 | 首轮测量 |
| --- | --- |
| 建立合成索引 | 3.686 秒 |
| 查询 P50 | 23.17 ms |
| 查询 P95 | 48.15 ms |
| 查询 P99 | 49.26 ms |
| 查询最大值 | 56.36 ms |

计时从数据库查询调用到返回结果，包含候选筛选、排序与结果构造；不包含 GUI 120 ms 防抖和绘制，也不包含 NAS 枚举。此基线没有联网访问音乐根目录，不能当作实际 1 TB 首次扫描时间或网络性能。

桌面小库试听时一次进程快照：主窗口约 99.8 MiB，播放进程约 29.3 MiB，合计约 129.1 MiB 工作集。当时波形任务已结束；不是十万条、十客户端或长时间运行的峰值承诺。
