# 源音效管理工具 0.12.5 自动处理与校验复用预览

全库波形准备自动处理已记录和新发现的 NAS 路径异常：优先建立同一共享内的兼容硬链接，不支持或入口不可读时仅将该异常文件缓存到本机。首次需要在连接窗口授权 NAS；凭据仅留在本次运行的父进程内。连接中断或本机磁盘写入失败会保留游标并暂停，单项失败继续后面的文件。

首次使用兼容入口完整校验 SHA-256。已验证的文件身份、大小、纳秒级修改时间和状态时间未改变时，共享本机验证记录，不再每次播放、拖拽和准备波形都完整重读；身份或版本变化、记录不可用时重新校验。

继续全库准备会先重试历史异常，再从保存位置继续，不清空原有有效波形、参考波形或异常证据。界面的批次累计失败与当前去重待处理记录含义不同，不能当成坏文件数量。

原件名和音频内容保留；收藏、标签和原曲索引身份保留。硬链接与原件共享内容，软件只读使用，请勿用其他软件覆盖兼容入口。首次连接如 macOS 提示本地网络访问，请允许。该版本使用本机临时签名，尚未完成 Apple 开发者签名与公证。正式构建必须使用 mac-build/开始构建.command，保留官方 Qt Cocoa 修复及实际部署校验。

以下为历史构建记录，验收结论不自动代表 0.12.5。

## 给 Mac 同事的构建步骤

**修复版重建入口：**使用 [已回传验证的构建流程](../packaging/macos-0.12.0-verified-recipe/README.md)，其中 `build-macos-fixed.sh` 会部署重建的 Qt Cocoa 插件。以下原始包及 `prepare-macos.sh` 流程保留供依赖准备和历史参考，单独运行不会自动包含本次 Qt 修复，也不能直接作为最新版分发。

在 macOS 27 的 M 系列 Mac 上安装 Xcode 27 命令行工具和 Python 3，确保能访问 Qt 与 FFmpeg 官网。解压 `源音效管理工具-macOS27-同事构建包-0.12.0.zip`，进入其中的 `YuanAudio-macOS27-arm64-source-0.12.0` 目录，运行：

```bash
bash scripts/prepare-macos.sh
```

脚本准备 CMake、Ninja、Qt 6.11.2 和 FFmpeg 7.1.3 头文件，构建 arm64 应用，运行完整测试和打包后解码回归，检查应用内依赖与签名，并制作及校验 DMG。成功后请回传 `dist/源音效管理工具-macOS27-Apple芯片-0.12.0.dmg`、同名 `.sha256` 文件和 `dist/macos-build.log`；失败时也请回传完整日志。`.github/workflows/macos-27-arm64.yml` 可在配置好的 Apple Silicon 构建机上运行同一流程。

## 安装和实机验收

打开 DMG，把“源音效管理工具.app”拖进“应用程序”。这次请在**隔离的测试音乐目录和测试缓存目录**中完成以下检查，再接入正式资料：

1. 添加两个不同的音乐库，确认都可搜索、试听、定位文件夹，重启后仍在；移除其中一个时，另一个保持可用。
2. 分别对音乐库、下级文件夹和单首音乐选择“仅从列表移除”，确认 NAS 原文件仍在、未选中的音乐仍可用。文件夹和单曲从“设置 → 素材库”恢复排除项并重新收录；移除整个库后重新添加。真实文件删除只用特意创建的测试原件验证。
3. 在新的空共享缓存目录测试首次初始化，再测试已有有效 `library.json` 的共享目录复用和跨客户端波形读取。Mac 会先尝试无覆盖原子重命名，失败后尝试同样无覆盖的原子硬链接；若该 NAS 两种操作都不支持，软件会安全拒绝初始化。此时可先由 Windows 客户端在同一个空的专用共享目录初始化。硬链接后备路径必须在公司的实际 SMB 上验证。
4. 从软件的音频行或波形把整首文件拖进达芬奇 20/21 的媒体池和时间线，确认工程引用的仍是 NAS 原文件。先前测试只证明达芬奇能直接从 NAS 导入，未完成从软件出发的实际拖放验收。

0.12.0 修复版 DMG 只有 ad hoc 签名；没有 Apple Developer ID 签名与公证，回传 Gatekeeper 检查为拒绝。其他 Mac 可能阻止首次打开，不要关闭全局安全检查。公开发行前，应在受控 Mac 上设置 `APPLE_CODESIGN_IDENTITY` 和 `APPLE_NOTARY_PROFILE`，完成签名、公证和新镜像验收。参见 [Apple 的分发说明](https://developer.apple.com/macos/distribution/)。

0.12.0 已完成 Mac 原生构建及本次针对性闪退修复；上述未验收工作流和正式分发所需签名、公证仍未完成。重新运行未修复的原始构建包会丢失 Qt 修复，后续重建必须使用上面保存的修复流程并重新验证。
