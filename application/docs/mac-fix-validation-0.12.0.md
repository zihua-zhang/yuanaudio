当前安装镜像为 `源音效管理工具-macOS27-Apple芯片-0.12.0-Mac修复复测.dmg`，直接使用已核验的回传产物，不在 Windows 上修改或重新签名。桌面旧版 0.10.0 镜像移入项目归档，回传原件保留。

修复构建脚本、CMake 工程、上游补丁与许可证按回传原样保存于 `packaging/macos-0.12.0-verified-recipe/`，含文件哈希清单及重建布局说明。完整回传包另保存在 `dist/mac-fixed-0.12.0/`。这些材料不含新的 Mac 执行结果。

原始同事构建包仍是历史版本，不覆盖原文件或修改其哈希。主项目的旧 `prepare-macos.sh` / `build-macos.sh` 单独运行仍可能部署未修复的官方插件；**重建 Mac 版本必须使用已保存的修复流程并复验最终插件**。回传脚本依赖特定父目录布局、精确的 Qt 私有 ABI；后续必须使用全新构建目录，不能把回传的三个 Qt 文件当成完整 Qt 源码树。
