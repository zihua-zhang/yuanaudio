# 0.10.0 验证记录

## 本轮变更

- 对外名称改为“源音效管理工具”，添加原生 Windows 图标和窗口图标；内部用户资料位置继续使用 AudioLibrary，旧索引、收藏和波形缓存不迁移、不重建。
- 统一浅色、深色和跟随系统的界面配色。设置页即时切换并保存选择；列表、目录树、自绘波形、参考标记和状态提示同步换色。切换外观不触发音乐列表重建。
- 从同一个干净的 Windows 部署目录生成当前用户安装版、免安装 ZIP 和逐文件 SHA-256 清单。安装版可升级、卸载，用户资料保持在本机原位置。

## 已执行

- Release 构建成功，Windows 图标资源和 Qt 图标资源已进入 YuanAudio.exe。
- 完整 CTest 回归：25/25 通过。外观设置的持续性和波形换色有自动测试；另在原生 Windows 平台生成浅色、深色主窗口与设置窗口截图，并人工检查中文字体、层级和对比度。
- 部署清单：55 个程序和依赖文件，逐文件 SHA-256 与部署目录一致；免安装 ZIP 内所有文件均已逐项校验。安装版及免安装版包含同一个 YuanAudio.exe。
- 安装器在项目 test-output 下的独立目录静默安装成功；安装后的程序哈希与部署目录一致，注册的名称、版本、路径正确。对同一目录重复安装成功；安装后的程序用隔离资料目录启动并建立本机索引。静默卸载后程序文件、安装目录和卸载注册项均已移除。

## 当前边界

- 本轮没有对公司 NAS 的多人同时使用、达芬奇拖入、Mac 版或与出片的速度进行新验收。用户计划另行验证达芬奇。
- Windows 安装包尚未代码签名；首次打开时可能出现系统安全提示。尚未在另一台未配置开发环境的 Windows 电脑上执行独立验收。
