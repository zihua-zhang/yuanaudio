# 0.12：清透浅色 / 石墨深色

用户选定第一轮的两张概念图；第二轮的悬浮工作台、顶部音频台与上下波形排版不实施。

- 布局：统一顶栏（品牌、音乐搜索、添加、刷新、设置）→ 左侧浅缩进目录 + 右侧音乐列表 → 横贯窗口的紧凑播放条。
- 浅色：银灰侧栏、白色工作区、深石墨文字、灰蓝波形、蓝色播放进度。深色：中性石墨背景、柔银灰波形、低饱和蓝色播放状态，避免偏海军蓝。
- 字体：系统中文无衬线；主文字 14px，路径/辅助说明 12px，目录标题 22px。信息靠字号与留白分层。
- 形状：工作区不套大圆角边框；搜索和按钮保留克制圆角；统一线条图标。星标不再依赖字体字符的视觉形状。
- 目录：保留定位文件夹、浏览历史、个人工作区、多库及右键菜单；默认每级缩进 12px。保留可调宽度与旧偏好。
- 列表：每首一行，名称与路径双层，右侧宽波形和时长；虚拟绘制，无逐行常驻控件。
- 播放：全宽窄底栏，圆形播放按钮、当前文件、进度、时长、收藏、标签和音量。主波形点击与整首拖出保持原样。
- 性能：静态色块、矢量小图标、已有波形栅格缓存，禁止持续装饰动画、大面积实时模糊及整库预绘制。
- 验证：原有回归测试，真实 Qt 窗口截图（两主题、窄窗、设置）、主题切换状态保留、缓存绘制开销检查及打包后启动检查。

新界面不修改音乐原文件、个人数据格式或共享缓存身份。
