## 历史记录：0.2 与 0.1

以下保留当时实现和边界，不能作为当前版本的功能清单。0.2 的参考波形不持久化规则已被 0.5 的明确标记本机参考缓存替代；列表波形、读取限速、全库准备等也已在后续版本交付。历史“本次”均指原版本。

历史基准需求：产品文档 1.2；当时交付 Windows 开发预览 0.2，保留 macOS 构建入口。

## 0.2 测试驱动的修复

- 实际素材复现带封面 MP3 波形为空；波形改为 FFmpeg 音频轨道流式解码，保持逐声道、有界内存和独立进程。
- 播放压力测试复现同类 MP3 进度停在零；将媒体组件升级为 Qt 6.9.3 / FFmpeg 7.1.1。保留原文件，未剥离原件封面。
- 网络恢复后可直接点击播放或当前行重试；波形错误详情保留，不再被进程退出提示覆盖。
- 多人首次接入缓存改为完整配置独占发布，等待者直接读取已经完成的配置。死掉的远程初始化者留下的锁可在一分钟后恢复；恢复时不覆盖已存在的库 ID。
- 损坏数据包、损坏音频帧和截断 WAV 不再误存为正常波形；可读部分标为参考，禁止持久化该波形及不完整时长。
- 已新增回归用例、界面重试测试、200 次并发初始化、十个波形客户端、300 次连续切歌与九种编码检查。真实索引和小范围 NAS 只读结果见 `validation-0.2.md`。

以下保留 0.1 的实现记录，0.2 的现状以上述记录及 README 为准。

## 本次边界

- 不自动扫描公司整库；由用户在界面选择目录后启动。
- 首次只生成选中音乐的波形，不预解码整库。
- 不移动、删除、重命名或改写音频原件。
- Mac 实机、Resolve 外拖、生产 NAS 与十人负载需后续实测。
- 自动情绪识别、列表波形总览、项目副本、共享清理与自动对账留待后续迭代。

## 设计细化

- 原型采用 Qt Multimedia 的 FFmpeg 后端；播放和波形各运行在独立子进程。完整多级细节峰值暂以有界的逐声道全曲轮廓替代，峰值格式有独立版本，不能伪称逐采样细节。
- 搜索预先索引规范化 Unicode 单字和双字 token，候选经原文子串复核。数据始终写本机 SQLite。
- 扫描取消或失败保留旧索引；原型保守地保留缺失条目，不自动推断删除。
- 本机工具下载和构建产物被 Git 忽略。
