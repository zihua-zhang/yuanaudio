# 0.9.0 验证记录

日期：2026-09-25。Windows 预览版。

## 变更范围

- 音乐目录/搜索使用完整元数据列表，删除“加载更多”和 2,000 条显示限制。按单次索引快照稳定排序，主窗口查询、错误保留、历史位置与当前选择继续工作。
- 通过素材 ID 定位行，播放进度、波形和个人标记更新不再反复遍历所有结果。SQL 使用 forward-only 读取，同库身份与根路径字符串复用。
- 新增独立非模态设置窗口，含播放与浏览、波形缓存、性能、显示、素材库、快捷键。缓存操作从主窗口移入二级页面，仅保留底部状态入口。关闭设置保持试听和后台任务。
- 文件夹默认每级 12 个逻辑像素，可选 8 / 12 / 16；行距 44 / 52 / 60。音量、自动试听、剪辑优先、后台速度和显示设置即时应用并持久化。

## 验证

新增的完整列表回归覆盖 6 万 / 10 万条全部结果、中文多关键词、目录与收藏范围、取消旧查询、一致索引快照、文件版本匹配，以及滚到最后一行后保留选中和位置。设置回归覆盖六个页面、非模态窗口、关闭后保持试听与后台任务、偏好即时保存与重启恢复，以及最小窗口尺寸下控件可达。

补充修复旧波形异步返回时的时长写入：落盘同时匹配素材 ID、库、相对路径、文件大小和修改时间，避免旧结果覆盖新版音乐的时长；加入相应回归。

原生 Windows 窗口检查使用隔离资料目录和四段本机演示音频：主列表、六类设置导航、开关外观、显示选项的箭头、共享目录弹窗和关闭设置均正常。演示测试音量设为 0，不改实际工作音量；没有借助此测试向真实共享目录写入资料。

自动界面测试额外验证 980×640 主窗口、760×520 设置窗口；页面允许纵向滚动，主要操作没有横向裁切。新增开关支持鼠标两端点击、空格切换、Tab 聚焦及禁用态，并不会误触主窗口播放。

## 回归结果

22 组测试全部通过。首次完整执行中 21 组通过，缓存刷新组的两条旧断言仍要求 0.8 的按钮文案；改成检查实际的待复查状态、错误提示和设置入口后，核心与缓存刷新两组重跑通过，退出码 0。该调整仅修改测试，生产二进制没有变化。

- 完整执行：130.24 秒；窗口恢复 54.61 秒，完整列表 5.14 秒，设置 1.27 秒。
- 修正旧断言后：核心 0.42 秒、缓存刷新 3.64 秒，共 4.07 秒。
- 音频处理、波形定位、后台读取预算、共享缓存、并发缓存、异常恢复、个人工作区均通过对应回归。
- 构建程序 SHA-256：`1b7c3ea1458c73692f332dfc2eb37fb0666428db59e26c047894f0e3ad8586fb`。正式包复制同一程序，不重新构建。

## 交付状态

便携包与桌面入口为 0.9.0。现有用户库继续使用原资料目录，不做数据库迁移；旧版窗口仍在运行，需关闭旧窗口后通过桌面入口打开新版。电脑操作工具无法恢复当时最小化的 0.8 窗口，因此没有宣称完成 59,443 首实际用户库的升级后核对，也没有中断其后台缓存任务。

正式便携包在未追加开发用 Qt 路径的环境下，以隔离资料目录成功启动；四首演示音乐与波形正常显示，程序随后正常退出。包内共 55 个文件，包含运行依赖、第三方声明与许可证；归档执行 CRC 和逐文件 SHA-256 校验，不包含用户索引、个人配置或音乐。

## 性能边界

完整元数据会比原来 50 行占用更多内存；波形仍按可见行准备、有界缓存，音乐原文件不进入全量列表缓存。旧查询在开始前和每 128 行读取时检查失效标记，不能即时打断 SQLite 正在执行的语句/排序；过期结果不会覆盖新范围。

合成元数据基准不代表 NAS 音频解码、声卡起播或整机显示延迟。已有共享准备与失败记录保留，界面升级不代表失败音乐已修好或全库准确分析完成。公司 6–10 客户端、Mac M4 Pro/macOS 27、Resolve 20/21 工程内拖放仍需对应实机验收。
