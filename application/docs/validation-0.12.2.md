# 0.12.2 解码恢复与 NAS 路径分类验证

日期：2026-10-27。执行环境：Windows 11、Qt 6.9.3、Qt 随附 FFmpeg 7.1.1；Mac 待同事构建复测。验证没有改动公司音乐、正式缓存或正式索引，没有清缓存、重建或重试全库。

## 已确认的问题与修复

旧解码器把整首音频累计的错误计数设为 32；第 33 次可恢复的 invalid packet/invalid frame 会终止并丢弃已有采样。新的逻辑跳过可恢复包错误，以解析是否取得进展约束重复重试；接收端连续 64 次无有效输出、解析端连续 8 次无字节进展后停止，保留已得到的有效采样。send/receive 的 EAGAIN 按 FFmpeg 随附头文件的状态机要求先接收再重送。

解析错误不再一律称为“网络读取中断”。文件打开/属性/读取失败为 source_unavailable；无法获得有效音频为 invalid_audio；可用音频伴随异常为 decode_warning；提前停止但有采样则保留部分参考波形，并保留停止原因。失败记录不再将所有 reference 的真实原因覆盖为“损坏”。正常路径不增加一次额外文件打开；仅访问异常时补充底层 QFile 错误。

异常波形保存诊断信息：实际解码长度、声明时长、错误数、首次错误前已解码长度、是否读到结尾、是否提前停止。AWV3 本机视图向后兼容读取 AWV1/AWV2；不更换缓存根、不使旧缓存失效、不自动重新分析全库。异常波形仍为参考，不能据此认定整曲无损或已经通过听审，也不会发布为完整共享波形。
