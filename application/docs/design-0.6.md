# 0.6 波形拖出与浅色工作台

授权：从波形直接拖整首原文件到达芬奇；整体更简洁、接近苹果桌面软件的克制质感。

设计取向：音频列表是主角，保留可见行绘制与轻量 Qt 原生组件。浅色导航面与白色内容面通过留白和细分隔区分；蓝色只用于选中、播放和主要操作。避免玻璃模糊、装饰性动画与密集卡片。

色彩：工作台 #F5F5F7，列表 #FFFFFF，侧栏 #ECEEF2，正文 #1D1D1F，次要文本 #6E6E73，强调 #007AFF。系统字体配中文回退，正文 13 px，标题 18 px，路径 11 px。圆角 8 px 控件、12 px 播放条；行高 52 px，主间距 12 / 20 px。

布局：顶部保留名称、音乐搜索、添加目录、刷新和波形缓存入口。左侧文件夹导航，右侧列表；紧凑播放器位于内容底部。缓存的详细控制可展开，关闭面板后任务照常运行，入口仍显示当前数量，异常暂停时自动展开，避免把重要状态藏起来。

```
音频素材库     [搜索当前范围音乐........]  添加目录  刷新  波形缓存
              [可展开的缓存状态与操作]
文件夹        当前文件夹                       包含子目录
查找目录      名称                  波形              时长
目录树        曲名 / 所在文件夹      ━━━━              3:24
              ……
              ▶ 当前音乐              时间      音量
```

审阅：这是面向长时间音频筛选的桌面工作台，不需要宣传标题或大卡片。主列表维持密度，波形用安静的灰蓝色；缓存操作不再长期占用两行主空间。浅色按用户本次的简洁苹果感取向选定，无重绘动画。

手势约定：小幅移动以内松开仍按原位置比例试听；超过系统拖拽阈值后拖出按下那一行的整首原文件 URL，仅 Copy，不剪切、不导出片段。拖动不改变正在试听的歌曲；取消拖动不触发补发点击。原来的名称拖拽继续保留。

验证：自动测试拖动阈值、取消/释放、错误行隔离、索引刷新打断手势、原文件 URL 与原有点击播放。界面在正常与最小窗口尺寸检查。达芬奇实际投放以现场可用状态为准，不把内部 URL 测试当作达芬奇工程验收。

实机审阅：初版标题重复长目录路径，已改为末级名称，完整范围放在悬停提示中。正常窗口与 980 × 640 客户区均检查通过；窄窗口仍保留可点击波形、时长和紧凑播放控制。配色统一到名称、目录、波形、参考标记、弹窗及拖拽预览，没有保留旧深色绘制。
