# 0.4.0 目录定位版：交付与验证

日期：2026-09-20。Windows x64 便携预览版。

本次完成优化方案的 0.4 阶段：左侧查找并定位真实文件夹、目录按需加载、明确音乐搜索范围、保留浏览位置。波形本机直读与试听缓存仍是后续阶段；本次没有完成与出片的同条件对比，不能据此声称全面超越。

## 使用变化

- 左侧输入文件夹名称或多个路径关键词，候选显示路径以区分重名；点击或按 Enter 后展开祖先、滚动并选中真实目录。中文组词期间不会误激活旧候选。
- 目录树分批载入，目录候选支持分页，取消旧版 10,000 个目录截断。切换查询时过期后台任务尽早退出。
- 右侧显示当前范围，支持“包含子文件夹”和“全部素材”。切换新文件夹清空旧音乐关键词，清空左侧搜索则保留当前定位。
- 前进/后退恢复目录、音乐关键词和列表位置；重开恢复最后浏览位置及已展开分支。音乐右键可在左侧定位所在文件夹。
- 保留行内波形点击定位试听和紧凑播放条；浏览目录不会打断试听。拖音乐名称仍输出整首原文件的 URL。
- 新版首次从旧本机索引取得一致性副本，不重新扫描 NAS。旧版程序和原数据库保留；新版后续收藏、标签和收录独立变化，兼容的本机波形文件继续复用。

最终测试曾出现共享缓存配置暂时不可读。使用 Windows 独占文件句柄复现 250 毫秒占用后，加入最多 500 毫秒的有限重试；无效配置不会被覆盖或当成正常配置接受。新增回归及最终完整测试均通过。

便携包还在不添加开发工具目录的环境中独立通过点击定位脚本，验证起始定位、暂停后定位、连续点击保留最后位置、过期事件隔离和等待期间暂停。此后仅补充文档、资源测量和打包复制规则，没有再修改产品代码。

## 目录查询基准

每组 540 次，包含打开本机数据库连接。测试程序是 `folder_benchmark`，数据见 `docs/benchmarks-0.4.json`。

| 数据集 | 音乐数 | 目录数（含根与祖先） | 中位数 | P95 | 最大值 |
|---|---:|---:|---:|---:|---:|
| 实际本机索引的一致性副本 | 59,443 | 1,414 | 0.676 ms | 1.024 ms | 2.077 ms |
| 合成数据 | 100,000 | 40,001 | 1.208 ms | 2.127 ms | 10.778 ms |

实际副本升级约 51 毫秒，不含取得初始一致性快照的时间。1,414 是当前索引推导的目录数，不是本次扫描整个 NAS 得到的目录清单。合成数据包含 2 万叶目录及其 2 万父目录。

以上是数据库查询耗时，不包括输入防抖、界面绘制、网络读取和声卡出声。软件自身的本机耗时记录到结果回调就绪为止，同样不应解释为屏幕已经显示完成。没有据此推算 NAS 首次导入速度。

## 原生界面与资源抽样

在最终 Windows 便携包中实际打开既有音乐库，检查中文候选、真实左侧目录展开和选择、右侧范围、重开后的浏览恢复、点击波形中段试听。试听以音量 0 验证播放位置和运行状态，未测量可听声音延迟。

最终资源测量采用 psutil 累计 CPU 时间差，连续约 10 秒、每秒一次。范围为新版主界面和播放子进程两个进程；既有波形已就绪、12 行可见、NAS MP3 正在静音试听，没有全库扫描或后台波形生成。

- CPU 按本机 12 个逻辑处理器归一化：平均 0.4425%，单次最高 1.041%。
- 两进程合计工作集：平均 113.596 MiB，最高 114.67 MiB。
- 两进程合计私有提交量约 93.5–93.9 MiB。

工作集包含共享页，不能与独占内存混为一谈。这只是当前场景短时样本，不是硬性资源上限、长时间稳定性或达芬奇同时渲染的保证。此前 PowerShell 采样的 CPU 差值异常为零，已排除，发布数据来自最终 psutil 采样。

另以只读方式检查旧库仍为 schema 2、新版为 schema 3，均为 59,443 条音乐。本次没有运行生产 NAS 全库扫描，也没有修改音乐原件。

## 尚未完成与交付取舍

1. 本次先交付可运行的 0.4，以便独立验证目录体验；代价是整体性能方案仍需继续实施。波形本机直读、共享预生成、近期音频缓存、统一资源预算及自动退让属于后续阶段。
2. 保留原有并行工作目录及版本，以独立索引保护旧版本；代价是迁移后的收藏、标签和收录不在两版间自动同步。波形格式未变，兼容缓存共用。
3. 输入法组词已用事件级测试覆盖，尚未遍历系统中文输入法；目录数据全量分页及界面按需加载分别有测试，尚未人工滚动遍历每一页。这些不作为完整实机覆盖的声明。
4. 低优先级待补：候选中的关键词高亮；扫描状态、最后更新时间与离线索引新鲜度提示。
5. Apple Silicon Mac、Resolve 20/21 内实际拖入工程、公司网络 6–10 人同时使用、长时间运行和与出片的公平对比仍未验收。本次没有交付 Mac 包，也未实现情绪识别。

交付保留在 `feat/inline-waveforms` 并行分支，无远程发布或合并。完整测试通过后保留原代码结果，只对文档和压缩包做交付检查，避免无新代码变化的重复测试。
